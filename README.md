# Automated Software Deployment System

An automated software deployment system designed to simplify application deployment using modern DevOps practices.

## Technologies

- Node.js
- Docker
- GitHub Actions

## Project Structure

- `server.js` - Application server
- `app.js` - Application logic
- `Dockerfile` - Docker configuration
- `deploy.sh` - Deployment script
- `.github/workflows/` - CI/CD workflows

## Running the Project

```bash
npm install
npm start
